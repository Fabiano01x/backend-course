# Checkpoints sequenciais

Esta pasta receberá uma solução completa e executável para cada aula
concluída:

```text
module-04/
├── lesson-01/
├── lesson-02/
└── lesson-03/
```

Um checkpoint novo deve partir do anterior, introduzir apenas o conceito da
aula atual, passar seus testes e ser registrado no mesmo commit da aula. Não é
permitido criar o checkpoint de uma aula enquanto a anterior estiver pendente.

O protótipo existente da aula 3 permanece em `reference/pilot/` e não deve ser
confundido com `module-04/lesson-03` até que as aulas 1 e 2 sejam produzidas.
